# dotfiles

My personal Arch Linux dotfiles for a Hyprland setup with Tokyo Night theme.

## Stack
- **WM**: Hyprland
- **Bar**: Quickshell
- **Terminal**: Kitty + Maple Mono NF
- **Editor**: Neovim
- **Notifications**: Mako
- **Wallpaper**: Wpaperd
- **Lock screen**: Hyprlock
- **FastFetch**: Fastfetch

## Install
```bash
git clone https://github.com/hro1025/dotfiles.git ~/.dotfiles
cd ~/.dotfiles
stow hypr quickshell mako wpaperd kitty nvim fastfetch bash
```
